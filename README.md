# СПИЧКА · Кофейная гуща

Мобильный браузерный прототип: интерфейс, изображения и анимации формируются из песчаных частиц.
Выделенная копия актуального кофейного билда на 4 октября 2026 года, без других экспериментов
и внутренней истории рабочего проекта.

[Открыть демо](https://spichka-digit-morph.vercel.app/gusha/#hello).

## Запуск

Нужны Node.js 20+ и Python 3.

```sh
npm ci
npm run build
npm run dev
```

Открыть http://localhost:5173/gusha/.
Все ресурсы локальные; ключи, токены и исходный видеоархив для запуска не нужны.
Содержимое `dist/` — исходники и готовые ресурсы. Не удаляйте эту папку как временную сборку.
`npm run build` проверяет синтаксис и наличие ресурсов; бандлинг не требуется.

## Флоу и тестовые данные

```text
hello → ticket → brewing → date → cup
  → phone? → code? → name → stories
  → sphere → sphere-ticket → stories → profile
```

- Оба восьмизначных билета: `00000000`.
- Используйте вымышленный номер. Код страны поддерживает 1–3 цифры.
- Имя и фамилия обязательны.
- По умолчанию `phone_only`: после телефона сразу имя, без SMS.
- `/gusha/?auth=full#hello`: SMS-ветка, демонстрационный код `1234`, ручное подтверждение.
- `/gusha/?auth=disabled#hello`: без входа.
- Полный разбор содержит 6 глав; отношения и бизнес — по 9, плюс финальная сводка.
- `#lens` — отдельный визуальный стенд; карта неба выключена в основном маршруте.

Это **автономное демо**, не боевой сервис: SMS не отправляются, билеты не активируются на сервере,
тексты примерные и не рассчитываются по дате рождения. Профиль и до 40 разборов сохраняются
в localStorage браузера по номеру; такая механика не является безопасной авторизацией.

## Устройство

| Файл | Назначение |
| --- | --- |
| `dist/gusha/app.js` | Маршруты, сеанс, одно ядро частиц и общий цикл кадров |
| `dist/gusha/sand.js` | WebGL / Canvas fallback, погода, физика, кеш целей и запекание течения |
| `dist/gusha/scene-kit.js`, `ui-kit.js` | Песочные кнопки и поля, доступные DOM-хит-зоны, safe-area / visualViewport |
| `dist/gusha/flow.js`, `readings.js` | Локальный архив, устойчивые ID разборов, демонстрационный контент |
| `dist/gusha/screens/` | Экранные модули с mount/unmount |
| `dist/gusha/hello-frames.bin` | Предрассчитанные полутоновые кадры интро для бумеранга |
| `dist/gusha/assets/` | Локальные изображения и иконки для целей песка |
| `dist/assets/` | Шрифт и общие данные созвездий/датчиков |

Системная клавиатура не перемонтирует поля. Длинные тексты делятся на страницы по метрикам
шрифта, а не обрезаются. При повторном открытии карточки сохраняется тот же результат.
Поддерживаются reduced motion, DPR-лимиты и остановка рендеринга скрытой вкладки.

## Проверки

При запущенном локальном сервере:

```sh
npx playwright install webkit
npm test
npm run test:regression
```

На Linux для браузера могут понадобиться системные зависимости:
`npx playwright install --with-deps webkit`.
Снимки сохраняются в `output/playwright/` (не в git).
Полный флоу проверяет оба билета и обе сферы, профиль, архив, повторный вход, режимы авторизации,
клавиатурный viewport, поворот и мобильные размеры от 320×568 до 844×390.
Регрессия включает старые сцены и отдельный проход FPS без снимков.
Для пропуска длительного FPS-прохода на macOS/Linux: `GUSHA_SKIP_FPS=1 npm run test:regression`.
Другой сервер задаётся переменной `GUSHA_BASE`.

Реальная клавиатура и системное меню share на iOS/Android требуют отдельной проверки на телефоне.

## Публикация и ресурсы

`vercel.json` публикует `dist/`. Секреты и настройки аккаунта Vercel в репозиторий не входят.
Для нового размещения привяжите репозиторий к собственному проекту хостинга.

Исходное видео не публикуется. Для необязательной пересборки интро положите свой
совместимый референс в `Refs/hello-video.mp4` и запустите
`python3 scripts/build-hello-frames.py` (требуется ffmpeg).
Готовые кадры уже включены в репозиторий.

Шрифт Cormorant Garamond распространяется по OFL: `dist/assets/OFL.txt`.
Фото, референсы и дизайн-ресурсы не объявляются свободно лицензированными;
для самостоятельного коммерческого использования проверьте права или замените их.
Публикация этого репозитория сама по себе не выдаёт лицензию на все его материалы.
